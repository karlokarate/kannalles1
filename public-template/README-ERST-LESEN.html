KH Checker

Diese ZIP ist direkt für den vorhandenen GitHub-Pages-Workflow gebaut. Die fertige PWA liegt im ZIP-Stamm; ein eigener Server ist für den normalen Betrieb nicht erforderlich.

ZIP unverändert hochladen: Lege kh-checker-v__KH_APP_VERSION__-komplett.zip im Repository unter releases/ ab. Nicht vorher entpacken und nicht neu verpacken.

Deployment über GitHub Actions

  1. Datei als releases/kh-checker-v__KH_APP_VERSION__-komplett.zip hochladen.
  2. Unter Actions den Workflow Build, validate and deploy KH Checker PWA starten.
  3. mode=release_zip wählen und als zip_path exakt releases/kh-checker-v__KH_APP_VERSION__-komplett.zip eingeben.
  4. Nach erfolgreichem Lauf die vom Workflow ausgegebene Pages-Adresse öffnen.

Was auf dem Gerät läuft

Direkte Produktsuche

Search-a-licious wird primär direkt per HTTPS aufgerufen. OFF Legacy Search folgt höchstens einmal nach Fehler oder null Treffern.

Lokaler Cache

Fresh-/Stale-Cache, Request-Deduplizierung, Kalibrierungen, Verlauf und Berechnung laufen lokal in der PWA.

Gezielte Details

Nur das ausgewählte Barcode-Produkt wird über OFF API v3.6 geladen. v2 ergänzt nur weiterhin fehlende Nährwerte.

Kontrollierte Fehler

Kein lokaler Cooldown: technische Details bleiben sichtbar und ein manueller Retry ist sofort möglich.

Installation

  • iPhone/iPad: Pages-Seite in Safari öffnen → Teilen → Zum Home-Bildschirm.
  • Android: Pages-Seite in Chrome öffnen → App installieren.
  • Desktop: Installationssymbol eines PWA-fähigen Browsers verwenden.
Nicht per file:// betreiben: Service Worker und PWA-Installation benötigen einen sicheren HTTP(S)-Kontext. GitHub Pages stellt ihn bereit.

API auf dem Zielgerät prüfen

API-DIAGNOSE.html testet Search-a-licious, den Legacy-Fallback sowie OFF API v3.6 und v2 einzeln. Der tatsächliche Browserfehler, Endpunkt, Status und die Laufzeit werden angezeigt.

Validierung

Der Release-Gate umfasst Vitest, TypeScript, Biome, Playwright auf Chromium/WebKit, axe-core, npm audit, Service-Worker-/Manifest-Prüfung, mobile Unterpfade, sichere ZIP-Extraktion und vollständige SHA-256-Prüfsummen.

App öffnen API-Diagnose öffnen

Enthalten: fertige PWA, Diagnose, maschinenlesbarer Vertrag, Dokumentation, Release Notes, Lizenz und Prüfsummen. Der Entwickler-Quellcode wird separat ausgegeben.
